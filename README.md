# ORBIT

궤도 회전형 원버튼 리듬게임. 서로 붙어 있는 두 행성 중 하나가 축이 되고, 다른 하나가 박자에 맞춰 그 주위를 돈다. 공전 행성이 다음 타일 방향에 닿는 순간 아무 키(또는 화면 터치)를 누르면 두 행성의 역할이 바뀌며 길을 따라 전진한다. **길의 모양 자체가 리듬이다** — 직진은 1박, 꺾이는 각도에 따라 박 길이가 달라진다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # Vitest 단위 테스트
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
```

## 조작

- 플레이: Esc를 제외한 아무 키 / 터치. Esc = 일시정지(실패 화면에서는 나가기).
- 레벨 선택: 방향키 선택, Enter 시작, 카드 더블클릭.
- 에디터
  - D/W/A/S = 0°/90°/180°/270°, E/Q/Z/C = 45°/135°/225°/315° 타일 추가 (선택 타일 뒤)
  - Shift+방향키 = 나가는 각도 ±15°, ←/→ 선택 이동, Home/End, Backspace 삭제, T Twirl 토글
  - Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z) 실행 취소/다시 실행, Ctrl+S json 저장
  - Space 선택 타일부터 플레이테스트, 휠 줌, 드래그 이동, F 선택 타일로 카메라 이동
  - 하단 타임라인: 파형 + hitTime 마커 (휠 스크롤, Ctrl+휠 확대, 드래그, 마커 클릭 선택)

## 레벨 형식

`level.orbit.json` + 음원(+ 배경 이미지)을 zip 또는 폴더로 묶는다. 형식은 설계서 3장을 따르며, 추가로 `Text` 이벤트(안내 문구)를 지원한다. 음원이 없으면 레벨의 hitTime에 맞춘 합성 비트가 자동으로 재생된다.

## 구조

```
src/
  core/     순수 로직 — 각도·박·시간 계산(chart), 판정(judge), 통계, 레벨 검증, 연출 타임라인, 에디터 조작
  audio/    AudioContext 엔진 + 마스터 클럭, 효과음 합성, 합성 비트 트랙
  render/   PixiJS v8 — 트랙(컬링), 행성, 파티클/판정 텍스트, 스테이지·카메라
  game/     게임 루프·상태 머신, 입력 수집, 사용자 설정
  editor/   레벨 에디터 (단축키, 이벤트 편집, 녹화, 파형 타임라인)
  ui/       타이틀, 레벨 선택, 게임 HUD·결과, 설정, 오프셋 보정
  levels/   데모 레벨(코드 생성), 패키지 불러오기/내보내기, 라이브러리
tests/      Vitest
```

게임 진행 시각은 오직 오디오 기반 마스터 클럭(`AudioEngine.songTime`)에서 읽는다. 입력은 `event.timeStamp`를 같은 클럭으로 변환해 판정한다. 설계 중 확정한 세부 결정은 [DECISIONS.md](DECISIONS.md)에 있다.

데모 레벨 3개(튜토리얼·지그재그·가속)는 모두 코드로 생성되며, 음악도 Web Audio로 레벨 hitTime에 맞춰 합성한다. 저장소에는 외부 음원·이미지·폰트가 없다.
