# 음악 넣기 가이드

ORBIT 레벨은 `level.orbit.json` 한 파일과 음원 파일로 이루어진다. 음원이 없으면 레벨의 박에 맞춘 합성 비트가 대신 재생된다.
**저작권이 있는 곡은 저장소에 커밋하지 말 것.** 직접 만든 곡이나 사용 허가를 받은 곡만 포함한다.

지원 형식: 브라우저가 디코딩할 수 있는 형식 (mp3, ogg, wav, m4a/aac, flac — 브라우저마다 다름. mp3·wav가 가장 무난).
**동영상 파일(mp4·webm, 브라우저에 따라 mov·mkv)도 된다** — 오디오 트랙만 꺼내 곡으로 쓰고, 영상은 화면에 나오지 않는다. 소리가 없는 영상이나 지원하지 않는 코덱이면 안내가 뜬다. 배포본에 포함할 때는 용량 때문에 mp3로 바꾸는 편이 낫다.

## 동영상·큰 파일을 mp3로 바꾸기

**레벨 선택 → "동영상 → mp3"** (에디터 위쪽에도 있음). 동영상(mp4·webm·mov 등)이나 wav를 고르면 소리만 꺼내 mp3로 바꾼다.
파일은 인터넷에 올라가지 않고 기기 안(브라우저)에서만 변환된다. 음질 128/192/320kbps 선택.

- 변환 후 **mp3 저장** 또는 **이 곡으로 레벨 만들기**.
- 배포 링크(claude.ai 화면)에서는 mp3를 직접 저장할 수 없어 **mp3가 든 zip**으로 저장된다. 이 zip은 그대로 "음원으로 레벨 만들기"·"음원 선택"에 넣을 수 있다.
- 배포 링크에 곡을 넣을 때 파일당 15MB 제한이 있는데, mp3 192kbps면 약 10분까지 들어간다.

## 음원이 없을 때: 음악 자동 생성

**레벨 선택 → "음악 자동 생성"** (또는 에디터 상단 버튼). 분위기(신나는·잔잔한·빠른·어두운), 길이(30초~3분), BPM, 난이도를 고르면
게임이 곡을 직접 작곡해 드럼·베이스·멜로디·화음으로 합성하고, **작곡한 음표 위치에서 바로** 레벨을 만든다 (분석이 아니라 음표를 알고 있으므로 박자가 정확).

- 난이도: 쉬움 = 킥·스네어, 보통 = + 멜로디, 어려움 = + 베이스. 빈 곳은 하이햇 등 다른 악기 소리가 나는 박으로 채운다.
- 매번 새 곡(무작위 seed). 에디터에서 zip으로 내보내면 곡(wav)과 레벨이 함께 저장된다.
- 구성: 인트로 2마디 → A/B/A/C(브레이크) 8마디씩 → 아웃트로 2마디. 레벨은 인트로 뒤에서 시작.

## 0. 가장 빠른 방법: 음원만 넣으면 자동 생성

- **레벨 선택 → "음원으로 레벨 만들기"** → 곡 파일 선택 → 난이도(쉬움/보통/어려움) 선택.
  곡을 분석해 BPM·첫 박을 찾고, 킥·스네어 같은 강한 소리가 나는 박마다 타일을 만들어 목록에 바로 추가한다. Enter로 플레이.
- **에디터**: 빈 레벨에서 **음원 선택**을 하면 자동으로 타일이 생긴다. 다른 난이도로 다시 만들려면 음악 맞추기 → **타일 자동 생성 → 생성**.
  BPM·첫 박을 직접 맞춰 두었다면 "현재 BPM·첫 박 사용"을 켜고 생성한다.
- 난이도: 쉬움·보통·어려움 = 반박(8분음표) 격자, **매우 어려움 = 16분음표 격자**(최소 간격 120ms), **극한 = 16분음표 + 셋잇단**(최소 100ms). 빠른 곡에서 격자가 너무 촘촘해지면 그 격자는 자동으로 뺀다.
- 자동 생성 규칙: 격자 위에서 소리가 강한 지점을 고른다(난이도가 높을수록 잔 리듬이 많음). 입력 간격은 최소 200ms(쉬움~어려움), 1.5박보다 긴 빈 곳은 1박 타일로 채운다. 트랙이 겹치지 않도록 필요한 곳에 회전 반전을 넣는다. 체크포인트·색 변경 같은 이벤트는 넣지 않으므로 필요하면 에디터에서 직접 추가한다.
- 한계: 템포가 도중에 바뀌거나 흔들리는 곡(라이브 연주 등)은 뒤로 갈수록 어긋난다. 이런 곡은 1번 방법(녹화 모드)으로 만든다. 자동 생성 결과는 에디터에서 자유롭게 고칠 수 있다.

## 1. 에디터에서 곡에 맞춰 레벨 만들기

1. 타이틀 → **레벨 에디터** → 상단 **음원 선택**으로 곡 파일을 고른다.
2. 오른쪽 **음악 맞추기**
   - 곡을 고르면 **BPM · 첫 박**을 자동으로 추정한다. 결과가 맞으면 **적용**.
     (첫 박은 카운트다운이 들어가도록 1초 이후의 박으로 맞춰진다.)
   - 추정이 틀리면 **탭 템포**를 곡에 맞춰 4번 이상 눌러 BPM을 구한다. 절반/두 배로 나오면 레벨 설정의 BPM을 직접 고친다.
   - **▶ 선택 타일부터 타격음과 듣기**로 타격음이 곡의 박과 맞는지 확인하고, 어긋나면 **offset 미세 ±10ms / ±1박**으로 조정한다.
     하단 파형의 `offset` 표시와 흰 세로선(hitTime)이 곡의 킥·스네어와 겹치면 맞은 것이다.
3. 길 만들기
   - **녹화 모드**: 선택 타일부터 곡이 재생되고, 곡의 리듬에 맞춰 아무 키나 누르면 그 간격대로 타일이 만들어진다 (1/12박 단위).
     - **녹화 속도 ×0.75 / ×0.5**: 곡을 느리게 틀고 쳐도 타일은 원래 속도 기준으로 만들어진다. 빠른 구간을 정확히 칠 때.
     - **덮어쓰기**: 선택 타일 뒤를 지우고 녹화. 틀린 구간만 다시 녹화할 때.
   - **단축키**: D/W/A/S/E/Q/Z/C로 한 타일씩. 각 타일 옆 숫자가 박 수.
   - **직진 채우기**: 1박 직진 타일을 N개 붙인다 (BPM을 적으면 그 지점에 속도 변경도 넣음).
   - 곡 중간에 템포가 바뀌면 그 타일에 **속도 변경(SetSpeed)** 이벤트를 넣는다.
4. **Space**(플레이테스트)로 확인 → **zip 내보내기**로 곡과 레벨을 함께 저장한다.

## 2. 만들어 둔 레벨 불러오기

레벨 선택 화면의 **레벨 불러오기 (zip / json)** 또는 **폴더 불러오기**. zip/폴더 안에 `level.orbit.json`과 `songFile`에 적힌 이름의 음원이 있으면 된다.
(불러온 레벨은 그 세션 동안만 목록에 남는다.)

## 3. 배포본에 곡 포함하기 (`public/levels/`)

빌드 결과에 기본으로 들어갈 레벨은 `public/levels/`에 둔다. 앱은 시작할 때 `levels/index.json`을 읽어 목록에 추가한다.

```
public/levels/
  index.json            ← ["my-song", "example"]  (폴더 이름 배열, 이 순서로 목록에 추가)
  my-song/
    level.orbit.json    ← settings.songFile: "song.mp3"
    song.mp3
    bg.jpg              ← (선택) Background 이벤트의 image
```

1. 에디터에서 **zip 내보내기** → 압축을 풀어 `public/levels/<폴더 이름>/`에 넣는다. (레벨 파일 이름은 반드시 `level.orbit.json`)
2. `public/levels/index.json`에 폴더 이름을 추가한다.
3. `npm run dev`로 확인 → `npm run build`면 `dist/levels/`에 함께 복사된다.

폴더 이름은 영문·숫자·한글·`-`·`_`·`.`·공백만 쓸 수 있다. 음원을 찾지 못하면 콘솔 경고를 남기고 합성 비트로 재생한다.

## 레벨 파일에서 음악과 관련된 값

| 키 | 의미 |
|---|---|
| `settings.songFile` | 패키지 안의 음원 파일 이름 |
| `settings.bpm` | 시작 BPM (1박 = 직진 한 칸) |
| `settings.offset` | 첫 박(타일 0에서 공전 시작) 시각, 초. 첫 입력은 그다음 박 |
| `settings.pitch` | 재생 속도 배율 — 곡과 판정 시각이 함께 바뀐다 |
| `settings.volume` | 곡 볼륨 0~1 |
| `settings.countdownTicks` | 첫 박 전 카운트다운 틱 수 |
| `meta.previewStart` | 레벨 선택 화면 미리듣기 시작 위치, 초 |
| `SetSpeed` 이벤트 | 그 타일부터 `bpm` 또는 `multiplier`로 템포 변경 |

## 리듬으로 레벨 쓰기 (코드)

`src/levels/builder.ts`의 `LevelBuilder`는 박 수만 주면 길 모양을 계산한다. 곡의 리듬을 그대로 적으면 된다.

```ts
const b = LevelBuilder.create({ title: '내 곡' }, { bpm: 128, offset: 1.23, songFile: 'song.mp3' });
b.straight(8)                     // 4분음표 8개
 .beats(0.5, 1.5, 0.5, 1.5)       // 8분 + 점4분
 .checkpoint().twirl()            // 회전 방향 반전
 .beats(0.75, 1.25)               // 스윙
 .beats(2 / 3, 4 / 3)             // 셔플(3연음 느낌)
 .pause(2).hold(2)                // 쉼표, 홀드
 .speed(160).straight(8);         // 템포 변경
const level = b.build();
```

`RHYTHMS`에 자주 쓰는 조각(stairs, swing, shuffle, synco, dotted…)이 있다.
